
# PetStop Stock Control System

## Overview

PetStop is a Java-based stock control system developed as part of my programming project.

The system manages pet shop products, including food and accessories, and supports customer and staff operations.

## Features

- Manage food and accessory products
- Display and update stock information
- Customer and staff menus
- Low-stock notifications
- Product data persistence using Java serialization

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Inheritance
- Encapsulation
- Polymorphism
- Abstraction
- ArrayList
- File handling and serialization
- Exception handling

## Project Structure

- `Driver.java` – Main program flow and menu operations
- `Customer.java` – Customer information
- `Product.java` – Abstract parent class for products
- `Food.java` – Food product subclass
- `Accessories.java` – Accessories product subclass

## How to Run

1. Download or clone this repository.
2. Open the project in BlueJ or a Java IDE.
3. Compile the Java classes.
4. Run the `Driver` class.

## What I Learned

This project helped me develop my understanding of object-oriented programming, inheritance, polymorphism, file handling, and managing data using Java collections.
